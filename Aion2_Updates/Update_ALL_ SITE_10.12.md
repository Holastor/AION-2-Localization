        <h2 id="alpha-[콘텐츠_및_시스템]-1"><span style="color: rgb(0, 112, 192);"><u><strong>[Контент и Системы]</strong></u></span></h2>
        <h3 id="alpha-월드_거래소-2"><strong>Мировая биржа</strong></h3>
        <ul>
            <li>
                <div data-contents-type="text">Открыта новая Мировая биржа (Биржа кинаров, Обменник кюны), где можно свободно торговать с пользователями других серверов своей расы.</div>
            </li>
            <li>
                <div data-contents-type="text">Существующая биржа продолжает работать в обычном режиме.</div>
            </li>
            <li>
                <div data-contents-type="text">Налог на продажу на Мировой бирже составляет 20%.</div>
            </li>
            <li>
                <div data-contents-type="text">Лимит регистрации продаж на Мировой бирже/обменнике составляет по 10 раз для каждого.</div>
            </li>
            <li>
                <div data-contents-type="text">Все биржи доступны только пользователям с членством (Membership).</div>
            </li>
            <li>
                <div data-contents-type="text">Новые серверы (Фоэта/Исхальген) могут использовать только биржу существующих серверов.</div>
                <div data-contents-type="text"><br class="ProseMirror-trailingBreak"></div>
            </li>
        </ul>
        <h3 id="alpha-멀티_채팅_팝업_추가-3"><strong>Всплывающие окна мульти-чата</strong></h3>
        <ul>
            <li>
                <div data-contents-type="text">Добавлена функция всплывающего режима чата, позволяющая добавлять несколько окон чата в HUD и свободно размещать их.</div>
            </li>
            <li>
                <div data-contents-type="text">Вы можете добавить окно, выбрав нужную вкладку в общем чате и нажав значок всплывающего режима в верхней части.</div>
                <div data-contents-type="text"><br class="ProseMirror-trailingBreak"></div>
            </li>
        </ul>
        <h3 id="alpha-키나_드랍_제한-4"><strong>Ограничение выпадения кинаров</strong></h3>
        <ul>
            <li>
                <div data-contents-type="text">Ежедневный лимит получения кинаров изменен: 2 млн → 1 млн.</div>
            </li>
            <li>
                <div data-contents-type="text">При достижении лимита получения кинаров, выпадение предметов также ограничивается.</div>
            </li>
            <li>
                <div data-contents-type="text">У персонажей с ограниченным получением кинаров информация отображается в окне баффов, также это можно проверить в информации о членах группы.</div>
            </li>
            <li>
                <div data-contents-type="text">Время существования выпавших предметов изменено на 2 минуты.</div>
                <div data-contents-type="text"><br class="ProseMirror-trailingBreak"></div>
            </li>
        </ul>
        <h3 id="alpha-열쇠_전용_히든_큐브_추가-5"><strong>Добавление скрытых кубов для ключей</strong></h3>
        <ul>
            <li>
                <div data-contents-type="text">По всей Атрее добавлены скрытые кубы, которые можно открыть только с помощью ключа.</div>
                <div data-contents-type="text"><br class="ProseMirror-trailingBreak"></div>
            </li>
        </ul>
        <h3 id="alpha-어비스_보상_추가-6"><strong>Добавление наград Бездны</strong></h3>
        <ul>
            <li>
                <div data-contents-type="text">В меню «Преобразование материалов > Особое > Расходные материалы» добавлен рецепт для «Серебряной медали».</div>
            </li>
            <li>
                <div data-contents-type="text">В качестве материалов используются «Серебряный осколок заслуг (Печать)» и кинары. С вероятностью 10% можно преобразовать в «Серебряную медаль». (10 раз в неделю на персонажа)</div>
            </li>
            <li>
                <div data-contents-type="text">«Серебряный осколок заслуг (Печать)» можно получить при убийстве элитных монстров в Бездне.</div>
                <div data-contents-type="text"><br class="ProseMirror-trailingBreak"></div>
            </li>
        </ul>
        <h3 id="alpha-전투_상태_설정-7"><strong>Настройка боевого статуса</strong></h3>
        <ul>
            <li>
                <div data-contents-type="text">В зонах, где возможна настройка боевого статуса, исцеление и баффы не применяются к союзникам, имеющим отличные от ваших настройки.</div>
            </li>
        </ul>
        <div data-contents-type="text"><br class="ProseMirror-trailingBreak"></div>
        <h3 id="alpha-UI_개선사항-8"><strong>Улучшения интерфейса (UI)</strong></h3>
        <ul>
            <li>
                <div data-contents-type="text">Биржа</div>
                <ul>
                    <li>
                        <div data-contents-type="text">В окне регистрации продажи цена за единицу теперь автоматически заполняется по минимальной цене сделки.</div>
                    </li>
                    <li>
                        <div data-contents-type="text">Если минимальной цены сделки нет, автоматически вводится минимально возможная сумма.</div>
                    </li>
                    <li>
                        <div data-contents-type="text">Добавлена функция сортировки списка предметов биржи.</div>
                    </li>
                    <li>
                        <div data-contents-type="text">По рангу (высокий/низкий), по количеству лотов (много/мало), по минимальной цене продажи (высокая/низкая).</div>
                    </li>
                </ul>
            </li>
            <li>
                <div data-contents-type="text">Инвентарь и склад</div>
                <ul>
                    <li>
                        <div data-contents-type="text">При наведении мыши отображается окно подробной информации о предмете.</div>
                    </li>
                </ul>
            </li>
            <li>
                <div data-contents-type="text">Пантеон</div>
                <ul>
                    <li>
                        <div data-contents-type="text">Добавлена возможность проверять информацию о характеристиках Эмпирейского лорда через гиперссылку в эффектах украшений.</div>
                    </li>
                    <li>
                        <div data-contents-type="text">Добавлена функция быстрого перехода на биржу после выбора украшения.</div>
                    </li>
                    <li>
                        <div data-contents-type="text">Украшения теперь можно отправлять в чат в виде гиперссылок.</div>
                    </li>
                    <li>
                        <div data-contents-type="text">При получении нового украшения и добавлении его в список Пантеона будет отображаться красная точка (red dot).</div>
                    </li>
                </ul>
            </li>
            <li>
                <div data-contents-type="text">Титулы</div>
                <ul>
                    <li>
                        <div data-contents-type="text">Изменен порядок сортировки: титулы более высокого ранга отображаются сверху.</div>
                    </li>
                    <li>
                        <div data-contents-type="text">Новые полученные титулы теперь отображаются вверху, пока горит красная точка.</div>
                    </li>
                </ul>
            </li>
            <li>
                <div data-contents-type="text">Группа / Альянс</div>
                <ul>
                    <li>
                        <div data-contents-type="text">Улучшено отображение статуса участников в окне настроек (офлайн / вне зоны видимости / мертв и т.д.).</div>
                    </li>
                    <li>
                        <div data-contents-type="text">Улучшено отображение местоположения членов альянса на карте мира.</div>
                    </li>
                    <li>
                        <div data-contents-type="text">При распределении предметов по броску кубика, ваше выпавшее число теперь отображается в чате.</div>
                    </li>
                    <li>
                        <div data-contents-type="text">Права на установку меток в альянсе расширены до заместителей командира.</div>
                    </li>
                </ul>
            </li>
            <li>
                <div data-contents-type="text">Прочие улучшения</div>
                <ul>
                    <li>
                        <div data-contents-type="text">В узлах умений Даэваниона при наведении мыши отображается всплывающая подсказка, а в подробную информацию об узле добавлена гиперссылка.</div>
                    </li>
                    <li>
                        <div data-contents-type="text">Переработан интерфейс для наглядного отображения накопленных кинаров и очков Бездны, а также максимального лимита их получения.</div>
                    </li>
                    <li>
                        <div data-contents-type="text">Добавлено отображение оставшегося времени действия подписки.</div>
                    </li>
                    <li>
                        <div data-contents-type="text">В гардеробе теперь отображаются мили.</div>
                    </li>
                    <li>
                        <div data-contents-type="text">В список материалов для крафта добавлена кнопка быстрого перехода на биржу для предметов, которые можно продать/купить.</div>
