# 📘 Инструкция пользователя AION2 Localization Tool

Этот набор скриптов предназначен для распаковки, перевода, обновления и обратной упаковки языковых файлов игры (формат `.dat`) с использованием промежуточных форматов `.json` и `.po` (Gettext).

## 🛠 Установка и Подготовка

### 1. Требования
Для работы инструмента необходимо, чтобы на вашем компьютере был установлен **Python 3**.

*   **macOS:** Обычно предустановлен. Если нет — введите в терминале:
    ```bash
    brew install python
    ```
    или скачайте с [python.org](https://www.python.org/).
*   **Windows:** Скачайте и установите с [python.org](https://www.python.org/).
    > [!IMPORTANT]
    > Обязательно поставьте галочку **"Add Python to PATH"** при установке.

### 2. Первый запуск
В папке со скриптами находится файл запуска:
*   🍎 **macOS:** `run_tool.command`
*   🪟 **Windows:** `run_tool.bat`

**При запуске через `run_tool.command` или `run_tool.bat`:** Скрипт автоматически проверит наличие установленного python и необходимой библиотеки `polib`. Если её нет, он предложит установить её (нажмите `Y` и `Enter`).

## 🚀 Основные сценарии работы

Инструмент работает через главное меню с 6 режимами. Ниже описан каждый из них.

### 1️⃣ Распаковка файла игры (DAT → JSON)
Используется для извлечения текста из оригинального файла игры.

1.  Выберите пункт **1**.
2.  Введите путь к файлу `.dat` (например, `L10NString.dat`).
3.  Скрипт создаст файл `extracted_localization_....json`.
    *   Этот файл содержит все ключи и оригинальные тексты.

### 2️⃣ Подготовка к переводу (JSON → PO Files)
Используется для разбиения огромного JSON файла на удобные категории (Навыки, Квесты, UI и т.д.) в формате `.po`, который поддерживают профессиональные редакторы (например, Poedit).

1.  Выберите пункт **3**.
2.  Введите имя JSON файла, полученного на шаге 1.
3.  Скрипт проанализирует ключи и разложит их по папкам.
    *   Результат сохранится в папку: `po_dictonaries/`.
    *   Внутри будут файлы вида `SkillString_ASSASSIN.po`, `QuestString.po` и т.д.

> [!TIP]
> **Совет:** Открывайте файлы `.po` через программу **Poedit**. В ней удобно переводить: слева оригинал, справа — ваш перевод.

### 3️⃣ Сборка перевода (PO Files → JSON → DAT)
Когда вы закончили перевод в `.po` файлах, их нужно собрать обратно в игру.

#### Этап А: Объединение PO файлов
1.  Выберите пункт **4**.
2.  Выберите папку источника (обычно `1 - po_dictonaries`).
3.  Скрипт объединит все `.po` файлы из папки в один мастер-файл: `combine_localization.po`.

#### Этап Б: Конвертация в JSON
1.  Выберите пункт **5**.
2.  Введите имя файла: `combine_localization.po`.
3.  Скрипт создаст файл `translations_from_po.json`.

#### Этап В: Упаковка в DAT
1.  Выберите пункт **2**.
2.  Введите имя файла: `translations_from_po.json`.
3.  Скрипт создаст готовый файл для игры: `repacked_L10NString.dat`.

> [!WARNING]
> **Важно:** Скрипт пропускает строки с пустым переводом. В игру попадут только переведенные строки.

### 🔄 Обновление перевода (Sync Localization)
Используется, когда вышла новая версия официального английского перевода, и нужно перенести старый перевод на новую версию, отметив изменения.

1.  Распакуйте новый файл `.dat` от новой версии игры (см. режим 1), чтобы получить свежий JSON.
2.  Убедитесь, что ваши старые переведенные `.po` файлы лежат в папке `po_dictonaries`.
3.  Выберите пункт **6** в меню.
4.  Введите путь к новому JSON файлу.
5.  Скрипт сравнит новый файл со старыми переводами:
    *   **Новые строки:** Добавятся с пустым переводом.
    *   **Измененные строки:** Если разработчики изменили английский текст, старый перевод сбросится, но сохранится в "Комментариях" (в Poedit помечено как "Неточный" / Fuzzy).
    *   **Без изменений:** Перевод сохранится.
6.  Результат сохранится в новую папку: `po_comparison/`.
7.  Теперь работайте с файлами из `po_comparison` как с актуальными.

## 📋 Краткая справка по меню

| № | Название в меню | Что делает на самом деле | Входной файл | Выходной файл |
|:-:|---|---|---|---|
| **1** | DAT file → JSON file | Распаковка бинарника | `.dat` | `.json` |
| **2** | JSON file → DAT file | Упаковка перевода в игру | `.json` | `.dat` |
| **3** | JSON file → PO files | Категоризация и создание словарей | `.json` | Папка `po_dictonaries/*.po` |
| **4** | Combine PO files → PO file | Объединение всех PO в один | Папка с `.po` | `combine_localization.po` |
| **5** | PO file → JSON file | Подготовка к упаковке | `.po` | `.json` |
| **6** | Sync localization | Перенос перевода на новую версию | `.json` (новый) + старые `.po` | Папка `po_comparison/*.po` |

## ⚠️ Возможные ошибки и решение

### 1. `ModuleNotFoundError: No module named 'polib'`
*   Запустите `run_tool.command` или `run_tool.bat`, он предложит установить модуль.
*   Или введите в терминале:
    ```bash
    pip3 install polib
    ```

### 2. `File not found`
Убедитесь, что файл, имя которого вы вводите, лежит в той же папке, что и скрипт `localization_tool.py`, или указывайте полный путь к файлу.

### 3. Кодировки
Скрипты работают с **UTF-8** и **UTF-16 LE**. Если вы редактируете JSON вручную, используйте редактор вроде **Notepad++** или **VS Code** и сохраняйте в UTF-8.

### 4. Пустые строки в игре
Режим упаковки (**2**) пропускает строки, где `Localization_Value` пустое. Убедитесь, что вы заполнили перевод.
